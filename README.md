# GPT-6 Pixiv Recreation

This GitHub Pages site presents the supplied artwork at its original pixels through an HTML `<img>` element with a CSS-controlled, proportional layout. The image is not cropped, filtered, or redrawn, so the rendered artwork remains pixel-faithful at every viewport size.
